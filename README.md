# 朋友圈文案日更

> 篝火出品 · 收录于篝火 App 应用区

按商品信息和节日日历生成每天的朋友圈文案、配图建议和评论区首评，导出排期表，手动发布

![界面截图](docs/screenshot.png)

## 下载

到 [Releases](https://github.com/campfire-code/moments-daily-writer/releases/latest) 下载对应安装包：

| 电脑 | 文件 |
|---|---|
| Windows 10 / 11 | `moments-daily-writer_版本号_windows-x64-setup.exe` |
| Mac（Apple 芯片） | `moments-daily-writer_版本号_mac-arm64.dmg` |
| Mac（Intel 芯片） | `moments-daily-writer_版本号_mac-x64.dmg` |

第一次打开：
- **Windows**：如果弹出「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。
- **Mac**：如果提示「无法验证开发者」，打开「系统设置 → 隐私与安全性」，在下方点「仍要打开」。

## 怎么用

> 本工具**只生成文案和排期表，不做任何自动发布**，不登录、不连接微信。发布请自己手动复制到朋友圈。

**第一次用：先在「设置」里填大模型。** 打开「设置」，选一个服务商（推荐 DeepSeek 或通义千问，便宜、中文好），填上自己的 API 密钥和模型名。调用费用由你自己的账号承担，密钥只保存在本机。

1. 点「参数」，在「商品 / 品牌信息」里写清楚：卖什么、规格、价格、活动、面向谁、怎么下单。**AI 只会用你写的信息，不会编造价格和优惠**，没写活动就不会写折扣。可以参考 `samples/商品信息示例.txt`。
2. 选文案风格：每天轮换（默认，种草、日常、促销换着写，不容易像刷屏）、种草安利、促销活动、日常分享、节日营销。
3. 设好生成几天（1～30 天）、每天几条（1～3 条）、从哪天开始（不填就从明天开始）。
4. 「带配图建议」：每条附上拍什么、拍几张。「结合节日和电商节点」：节日当天和前 3 天会结合节日写或做预热。
5. 点「生成文案」。每条一张卡片：第一行是发布日期、建议时段、风格；下面是正文，再下面是【配图】和【首评】（发完朋友圈后自己在评论区补的第一条评论）。点「复制」复制这一条。
6. 全部生成完，自动在保存位置生成「朋友圈排期-开始日期起N天.xlsx」：序号、日期、星期、时段、风格、角度、节日节点、文案、字数、配图建议、评论区首评。

**内置的节日和电商节点**
- 每年固定：元旦、情人节、妇女节（女神节）、劳动节、青年节、520、儿童节、618、教师节、国庆节、双十一、双十二、平安夜、圣诞节。
- 按规则计算：母亲节（5 月第二个周日）、父亲节（6 月第三个周日）、感恩节（11 月第四个周四）。
- 农历节日只内置了 **2026 年**能确定的日期：除夕 2 月 16 日、春节 2 月 17 日、元宵节 3 月 3 日、清明节 4 月 5 日、端午节 6 月 19 日、七夕 8 月 19 日、中秋节 9 月 25 日。其他年份的农历节日、以及重阳、腊八、冬至等暂未内置。清明节会提示 AI 语气克制、不写促销。

**其他说明**
- 时段只是常见的朋友圈活跃时间参考（早上 7:30–8:30、中午 12:00–13:00、晚上 20:00–21:00），按你的客户作息调整。
- 每条调用一次大模型（同时 2 条），7 天 × 1 条就是 7 次。某条失败不影响其他条，排期表只收录成功的；想补上失败的，目前需要重新生成整批。
- 提示词要求不用「最」「第一」等广告法极限词、不写医疗功效，但发布前请自己再看一遍。

## 验收用例

需要先在「设置」里填好可用的大模型。文案每次不同，下面核对结构和规则。

| 操作 | 应得到 |
|---|---|
| 把 `samples/商品信息示例.txt` 的内容粘到「商品 / 品牌信息」，风格「每天轮换」，生成 7 天、每天 1 条，开始日期填 `2026-11-09`，点「生成文案」 | 出现 7 张卡片，日期从「11月9日 周一」到「11月15日 周日」，时段都是「晚上 20:00–21:00」；11月9日、10日标「双十一预热」，11月11日风格是「节日营销 · 双十一」；每张都有正文、【配图】、【首评】和「复制」按钮 |
| 等全部生成完 | 提示「排期表已保存：…/朋友圈排期-2026-11-09起7天.xlsx」；表格 7 行，「节日节点」列 11月9日写「双十一（2 天后）」、11月11日写「双十一」 |
| 每天几条改成 3，生成 1 天 | 3 张卡片，时段依次是早上、中午、晚上 |
| 关掉「带配图建议」再生成 | 卡片里没有【配图】，排期表没有「配图建议」列 |
| 「商品 / 品牌信息」留空点生成 | 每条都显示失败：「先在「商品 / 品牌信息」里写上要推广的内容」 |
| 「设置」里清空密钥后生成 | 显示失败：「还没有设置大模型：请到「设置」里填写接口地址、密钥和模型名」 |

自动测试（`pnpm test`）用假的大模型回复跑通了完整流程，并核对了节日日期（如 2026 年母亲节 5 月 10 日、父亲节 6 月 21 日、感恩节 11 月 26 日）。

## 自己编译

需要 Node.js 22、pnpm、Rust。

```bash
pnpm install
pnpm test          # 单元测试
pnpm tauri dev     # 开发运行
pnpm tauri build   # 打包
```

界面框架在 `src/kit`（所有 campfire-code 工具共用），本工具的逻辑在 `src/tool`。
